How to install the resource pack:

1. Press Win + R on your keyboard, type %appdata%\.minecraft and click OK.
2. Open the resourcepacks folder.
3. Move the downloaded revil_pack.zip file into this folder.
4. Launch Minecraft, go to Options -> Resource Packs, and select it!
